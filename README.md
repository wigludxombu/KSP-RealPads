# KSP-Vandenberg
A KK static that aims to recreate the vandenberg SLC-4E pad and landing zone.


# Coming soon :
Full workflow to create any launchpads (or interesting point you want to have in good resolution), just by yourself.
It will not be as detailed as the Vandenberg SLC-4E, BUT I'll make some more detailed versions of those places I like (I thought of starbase, Tanageshima, Naval Air Station Key West etc..) 

The individual buildings are made using the rough topoexport shape then a python script applies textures and shapes on it, that's why every building kinda looks the same, I try to do my best at avoiding that but the SLC-4E flight are mainly military ones so there's only a small amount of references to have, starbase will be much easier to do because of that.
